# Publishing and deployment

Keep these instructions with the source and distribution artifacts:

- [Windows distribution](distribution/windows.md): verified runtime packages, application builds, installers, signing, and release qualification.
- [Third-party compliance](distribution/third-party-compliance.md): payload provenance, licensing, notices, and corresponding source obligations.
- [Release history](../CHANGELOG.md): released changes and the next release candidate.
- [Installation and publishing](../README.md): the current public download and creator publishing workflow.
- [Security reporting](../SECURITY.md): supported releases and private reporting contacts.

Generated publishing packages carry their own publishing guide, metadata, and subtitle files. Preserve third-party license and notice documents inside distributed runtime and model packages.

The public website is maintained in the separate ReplayFoundry-Website repository; its deployment and recovery instructions are in `docs/PRODUCTION-OPERATIONS.md` there.
